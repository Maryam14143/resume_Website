My Website

Welcome to the repository of portfolio website! This project is a clean, responsive, and modern website designed to showcase skills, projects, and professional experience.

Live Demo
You can view the live website here: 
(https://maryam14143.github.io/resume_Website/)

Features
- **Clean UI/UX:** A modern and professional look for a better user experience.
- **Fast Loading:** Lightweight code for quick performance.
- **Contact Section:** An easy way for recruiters and clients to reach out.

## 🛠️ Technologies Used
- **HTML5:** For the structure and content of the site.
- **CSS3:** For styling, layout, and animations.
